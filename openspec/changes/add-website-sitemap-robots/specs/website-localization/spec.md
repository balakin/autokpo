## MODIFIED Requirements

### Requirement: Locale-aware SEO metadata

The system SHALL render locale-aware document language, title, description, canonical URL, and alternate-language links for each localized landing page. The XML sitemap generated by `@astrojs/sitemap` SHALL serve as the authoritative source of alternate-language links for search engine crawlers, complementing the `hreflang` meta tags already present in page heads.

#### Scenario: Document language matches locale

- **WHEN** a localized landing page is rendered
- **THEN** the page's `html` `lang` attribute matches the page locale

#### Scenario: Canonical URL matches locale route

- **WHEN** a localized landing page head is rendered
- **THEN** the canonical URL points to that locale's canonical route

#### Scenario: Alternate language links are available

- **WHEN** a localized landing page head is rendered
- **THEN** the page exposes `hreflang` alternates for Serbian Latin, English, and Russian routes

#### Scenario: Sitemap alternate links are consistent with hreflang tags

- **WHEN** a crawler reads both the page `hreflang` tags and the sitemap `xhtml:link` alternates for the same page
- **THEN** both sources reference the same set of locale URLs
